# 车迷驿——机车与车迷永远的家

你们好，各位！我是京局京段一只韶山九改，编号0047。每天看到火车迷拍摄我，我倍感荣幸。我曾经拉过很多旅客，也许其中也有车迷，抵达他们向往的目的地。但是我从来未与他们面对面交流过，我很想见到你们。

这里是我和你们永远的家。

也许我不能在接下来的日子里继续陪伴你们，也许我会化为一缸铁水，化身锅碗瓢盆。但是在这里，我的身影会被镌刻在一个个叫作像素的小方格里，在互联网的世界永生。你们是坚韧的铁道行者——火车迷，也会在这里留下你们的足迹和故事。

我经常在风里雨里看到你们寻觅的身影，我感受到了你们的热情。在这里，详细的铁路配线图为你们指引前进的方向；动车组交路查询帮你们找到远方的来客。久站而累，看会儿视频，坐下放松一下，手机连上预警器，不会让你们错过飞驰而来的列车。

山河有情，钢轨热忱，期待和你们在这里见面！

## 功能介绍

### 动车组交路查询、车站大屏

数据来源rail.re和openCRHtracker。可查询动车组最近的交路，数据仅供参考。

### 铁路地图

可以查看各个铁路的配线，包括道岔、正线等。可查看限速、电气化等。数据详细，来自OpenStreetMap

### 预警器连接手机功能

硬件研发中，后续补全。
